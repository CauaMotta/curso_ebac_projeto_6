# 🚀 Landing Page – Deadpool & Wolverine

Este projeto foi desenvolvido para o curso da **EBAC** como uma **landing page temática** de Deadpool & Wolverine, construído com foco em boas práticas profissionais de front-end.  
A estrutura foi criada em **HTML** e **Sass**, com automatização de tarefas como minificação de código e otimização de imagens utilizando **Gulp**.  
Além disso, a página conta com interatividade implementada em **JavaScript** e **jQuery**, e utiliza ícones do **Font Awesome** para enriquecer o design visual.

## 🛠️ Tecnologias Utilizadas

- 🌐 [HTML](https://developer.mozilla.org/pt-BR/docs/Web/HTML) – Estruturação do conteúdo
- 🎨 [CSS](https://developer.mozilla.org/pt-BR/docs/Web/CSS) – Estilização básica
- 🧡 [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) – Lógica e interatividade
- 💖 [Sass](https://sass-lang.com/) – Pré-processador CSS para estilos avançados
- 🔧 [Gulp](https://gulpjs.com/) – Automatização de tarefas (minificação, otimização)
- 💻 [jQuery](https://jquery.com/) – Manipulação simplificada do DOM e efeitos
- ⭐ [Font Awesome](https://fontawesome.com/) – Ícones para interface visual

## 📦 Instalação e Execução

Para rodar o projeto localmente, siga os passos abaixo:

```sh
# Clone este repositório
git clone https://github.com/CauaMotta/landingpage_deadpool_e_wolverine

# Acesse a pasta do projeto
cd landingpage_deadpool_e_wolverine

# Instale as dependências
npm install

# Rode o gulp para iniciar o projeto e automatizar tarefas
npm run gulp
